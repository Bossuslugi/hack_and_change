## Чек-лист подготовки перед записью

1. Запустить локальный сервер:
   ```bash
   # Терминал 1: Backend
   cd backend && go run ./cmd/server
   # Терминал 2: Frontend
   cd frontend && npm run dev
   ```
2. Открыть в браузере `http://localhost:5173`.
3. Нажать в панели стажёра кнопку **«Сбросить демо к началу»** (или `POST /api/v1/reset`), чтобы состояние очистилось до эталонного.
4. Выставить масштаб браузера на **100%** при разрешении экрана 1920×1080 (Full HD).
5. Проверить чёткость записи звука и следовать таймингам таблицы.
